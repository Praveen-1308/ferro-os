Native Windows (.msi / .exe) Execution Subsystem

Pure-Rust OLE installer unpacker, mimalloc 2.1 NTDLL interposition, and deterministic 500µs SchedExt quantum preemption.

📦

Pure-Rust MSI Extraction

rpk msi-extract parses OLE Structured Storage (CFBF) and unpacks embedded Cabinet streams directly into rootless prefixes in under 50 ms without spawning Windows installer daemons.

🚀

mimalloc 2.1 Heap Bridge

Replaces Windows Segment Heap lock bottlenecks. VirtualAlloc and HeapAlloc calls route directly into thread-local page-aligned free lists, achieving up to 35% higher heap throughput.

⚡

SchedExt 500µs Slicing

Eliminates Windows DPC interruptions and priority boosts. Binds Windows applications to dedicated CPU cores with a deterministic 500 µs preemption slice and Nice -10 realtime priority.

🛡️

Landlock LSM Sandboxing

Enforces kernel-level filesystem boundaries. Untrusted Windows binaries cannot touch private user data or system binaries outside their dedicated Wine prefix.

Head-to-Head Architectural Execution Pipeline

# 1. Inspect an MSI package's internal streams & embedded binaries
rpk msi-info PackageSetup.msi

# 2. Extract in pure Rust without running any Windows code (0 VM overhead)
rpk msi-extract PackageSetup.msi --target ~/.ferro/prefixes/trader_app

# 3. Launch Windows executable with mimalloc 2.1 & 500µs SchedExt quantum
ferro-core win-run ~/.ferro/prefixes/trader_app/TraderTerminal.exe --gaming --mimalloc

# 4. Run untrusted executables with kernel Landlock LSM confinement
ferro-core win-run UntrustedTool.exe --sandbox --prefix ~/.ferro/prefixes/sandbox1

Quick Start Guide

Run FerroOS locally in Docker or build native appliances in seconds.

Option 1: Launch Dedicated Server in Docker

git clone https://github.com/Praveen-1308/ferro-os.git && cd ferro-os
docker build -f Dockerfile.server -t ferro-os-server:latest .
docker run -d -p 8080:8080 -p 8088:8088 --memory=6g ferro-os-server:latest

Option 2: Launch Live Desktop via Web Browser (noVNC)

docker build -t ferro-os-web:latest .
docker run -d -p 6080:6080 --memory=6g ferro-os-web:latest
# Open http://localhost:6080 for interactive desktop access

Option 3: Run Multi-Persona Real-World Traffic Simulation

docker network create --subnet=172.28.0.0/16 sim_net
python3 tools/live_user_simulator.py --host 172.28.0.2 --port 8088 --users 1000 --duration 10
